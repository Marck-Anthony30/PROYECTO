# CineMax - Java 21

Proyecto sencillo para exposición.

Incluye:
- Venta de entradas
- CRUD de películas
- CRUD de clientes
- Boleta de venta

## Ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Seleccionar Java 21.
3. Ejecutar `CineMax.java`.

También se puede ejecutar con Maven:

`mvn javafx:run`
